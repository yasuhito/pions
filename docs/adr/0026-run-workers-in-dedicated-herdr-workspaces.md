# ワーカーを専用Herdrワークスペースで実行する

Pionsの可視ワーカーは、委譲元のペインを分割する兄弟ペインではなく、1つのオペレーションにつき1つ作成する専用のHerdrワークスペースの根ペインで実行する。`herdr workspace create --cwd <作業ディレクトリ> --label "Pions <短いOperation識別子>" --no-focus`で作成し、委譲元のワークスペース、タブ、ペインは対象にせず、フォーカスも移さない。これにより親画面は狭まらず、利用者はHerdr左側のワークスペース一覧から必要なときだけワーカーを表示できる。短いOperation識別子はオペレーション識別子の先頭8文字とし、表示名にタスク本文を含めない。この決定はADR-0005のペイン作成方法とADR-0009のペイン単位の終了処理を置き換え、ADR-0025が定めたワークスペース単位の運用を具体化する。

所有記録は、Herdrが返した不透明なワークスペース識別子と根ペイン識別子を`presentation_owned`として作成直後に永続化したものだけとする。ワーカー識別情報のペイン項目は所有記録の根ペインから設定し、`herdr agent start`はその根ペインを対象にする。Herdrは閉じたワークスペースの識別子を再利用しないため、現在のワークスペース一覧に所有記録と同じ識別子が存在することを同一性確認とし、根ペイン識別子やラベルの一致は同一性の証拠にしない。

表示終了処理は、結果受理とワーカー停止確認を終えた成功オペレーション、およびワーカー停止を確認できたキャンセル済みオペレーションだけを対象にする。処理識別子と対象ワークスペース識別子を結び付けた未完了記録を保存してから一覧を再照合し、一致した場合だけ`herdr workspace close`を実行して完了記録を保存する。照合不能、対象消失、またはclose失敗は`workspace_identity_unavailable`、`workspace_identity_missing`、`workspace_close_failed`として未確認に記録し、受理済みの結果やキャンセル済みの終端状態は変えない。失敗、停止を証明できないキャンセルによる状態不明、その他の状態不明ではワークスペースを調査用に残す。Pionsが作成・所有していないワークスペースは、識別子が一致しても閉じない。ランタイム復旧時には未完了記録を列挙して同じ照合を繰り返し、記録の存在だけからcloseを再実行しない。
