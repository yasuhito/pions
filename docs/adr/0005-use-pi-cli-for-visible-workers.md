# 可視ワーカーにPi CLIを使用する

Pionsの可視ワーカーは、SDK内で`AgentSession`を直接実行するのではなく、Herdrの兄弟ペインで実際の`pi` CLIを起動する。これにより、表示を模倣せずPi公式TUIをそのまま観測できる一方、意味上の完了と結果受理は引き続きPionsの認証済みワーカープロトコルだけで確定する。この決定はADR-0003を置き換える。

ワーカーはフォーカスを奪わない`regular`表示の観測専用TUIとし、Piの標準セッションは保存しない。信頼済みプロジェクトの`AGENTS.md`と、Pions専用の内部結果報告拡張だけを読み込み、通常のスキル、拡張、プロンプトテンプレートおよび入れ子委譲は提供しない。利用可能なツールは`read`、`grep`、`find`、`ls`、`bash`とし、読み取り中心のレビューを依頼するが、`bash`によるビルドやテストは妨げない。

タスク本文は所有者限定のファイルから読み込み、TUIのユーザーメッセージとして表示するが、プロセス引数やHerdrメタデータへ複製しない。内部拡張はPiのライフサイクルイベントと最終回答をワーカープロトコルへ報告し、結果受理の確認後に成功したPiプロセスとペインを閉じる。失敗時はPiプロセスとペインを調査用に保持する。キャンセル時は停止を確認できた場合だけ`Operation`をキャンセル済みとし、Piプロセスを終了して画面の残ったペインを保持する。停止を証明できない場合は状態不明としてプロセスとペインを保持する。

Piが高速に完了すると`herdr agent start`の起動完了判定と競合するため、初期プロンプトは起動時に送らない。内部拡張が認証済みプロトコルで識別情報と観測設定を報告し、`herdr agent start`が成功した後に、ホストが認証済みの`begin`を送って実行を開始する。
