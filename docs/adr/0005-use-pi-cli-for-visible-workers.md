# 可視ワーカーにPi CLIを使用する

Pionsの可視ワーカーは、SDK内で`AgentSession`を直接実行するのではなく、Herdrの兄弟ペインで実際の`pi` CLIを起動する。これにより、表示を模倣せずPi公式TUIをそのまま観測できる一方、意味上の完了と結果受理は引き続きPionsの認証済みワーカープロトコルだけで確定する。この決定はADR-0003を置き換える。

ワーカーはフォーカスを奪わない`regular`表示の観測専用TUIとし、Piの標準セッションは保存しない。信頼済みプロジェクトの`AGENTS.md`、Pions専用の内部結果報告拡張、およびPionsが監査して版を固定した選択モデル用プロバイダー拡張だけを明示的に読み込む。通常のスキル、許可していない拡張、プロンプトテンプレートおよび入れ子委譲は提供しない。`--no-extensions`を維持し、許可済み拡張も個別の`--extension`で指定する。利用可能なツールは`read`、`grep`、`find`、`ls`、`bash`とし、読み取り中心の作業を依頼するが、`bash`によるビルドやテストは妨げない。

`claude-bridge`プロバイダーでは、固定版`pi-claude-bridge`が公式Claude Agent SDKから未改変のClaude Codeを起動する。Claude Codeの内蔵ツールと`AskClaude`は使わず、Piから橋渡しした前記ツールだけを使う。利用者のClaudeログイン状態は`~/.claude`または`CLAUDE_CONFIG_DIR`から参照し、Pionsの設定や引数へ資格情報を複製しない。利用者設定がMCPの厳格検査、自動メモリー無効、追加利用禁止、`AskClaude`無効のいずれかを弱める場合は、起動前に拒否する。

タスク本文は所有者限定のファイルから読み込み、TUIのユーザーメッセージとして表示するが、プロセス引数やHerdrメタデータへ複製しない。内部拡張はPiのライフサイクルイベントと最終回答をワーカープロトコルへ報告し、結果受理の確認後に成功したPiプロセスとペインを閉じる。失敗時はPiプロセスとペインを調査用に保持する。キャンセル時は停止を確認できた場合だけ`Operation`をキャンセル済みとし、Piプロセスを終了して画面の残ったペインを保持する。Agent SDKを使うプロバイダーではキャンセル要求前にワーカーPiの子孫プロセスを開始トークンとともに捕捉し、Piと捕捉済みClaude Codeプロセスの両方の停止を確認する。子孫の捕捉、観測、終了のいずれかを証明できない場合は状態不明としてプロセスとペインを保持する。

Piが高速に完了すると`herdr agent start`の起動完了判定と競合するため、初期プロンプトは起動時に送らない。内部拡張が認証済みプロトコルで識別情報と観測設定を報告し、`herdr agent start`が成功した後に、ホストが認証済みの`begin`を送って実行を開始する。
