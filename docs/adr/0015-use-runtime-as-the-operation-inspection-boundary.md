# Piの正式レビュー操作の正本をRuntimeに置く

正式レビュー操作はADR-0025により削除した。現行の状態取得は[Pi拡張の利用案内](../pi-extension.md)を参照する。

Piから正式レビューを依頼する場合、既存の読み取り委譲へモードを追加せず、不透明なレビュー対象識別子と自己完結したレビュー内容だけを受け取る専用操作を使用する。この操作はRuntimeがオペレーションを作成した時点で識別子を返し、結果を待たない。モデル、思考量、ツール、ワーカープロファイル、許可主体、および許可時間枠は信頼済み拡張設定だけから与える。不完全な場合は既存の読み取り用プロファイルへ切り替えず拒否する。この設定境界は正式レビュープロファイルの本番有効化を意味しない。

Piからオペレーションを状態取得する場合、公開Runtime APIの`OperationReader.read()`が返す版付きスナップショットを正本とする。Pi拡張は、現在の信頼済みリポジトリに対応するRuntimeを開いてスナップショットを返す薄いツールだけを提供し、独自の状態機械、通知履歴、または私有の保存形式から状態を再構成しない。

状態取得は、状態、起動証跡、着手ゲート、実効・観測設定、開始配送、結果受理、停止確認、表示終了処理、および終了処理診断を同じスナップショットとして返す。一方、結果本文を含めず、検証済み結果の再取得はADR-0013で定めたRuntimeの結果再取得境界へ委ねる。識別子の照会またはスナップショット読み取りに失敗した場合は、別リポジトリにおける存在、保存状態、破損、または検査不能を区別できる詳細を返さない。

これにより、Pi拡張の表示都合が意味上のオペレーション状態を作ることを防ぎ、セッション内のRuntimeと再取得専用Runtimeで同じ永続状態を観測できる。状態取得は実行の再開、着手許可、または結果受理の権限を与えない。
