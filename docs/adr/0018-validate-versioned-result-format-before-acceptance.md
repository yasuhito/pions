# 版付き形式を検証してから結果を受理する

版付き結果形式を要求するオペレーションでは、形式の識別子、版、および信頼済み検証主体をオペレーション作成時に固定し、実際の結果バイト列がその形式と信頼済みの期待値に適合した場合だけ結果受理を成立させる。ワーカーに形式を選択・変更させず、同じ形式識別子の検証規則を進行中または保存済みのオペレーションに対して差し替えない。

信頼済みホストは、検証処理に実際に使用する規則と実装の正確なバイト列を登録成果物として渡す。Pionsはそのダイジェストを固定して同じ検証主体識別子と版への差し替えを拒否するが、信頼済みホストが渡した実行関数と登録成果物の対応を推測しない。

形式への適合は保存対象としての構造を検証するものであり、レビュー内容の正しさや外部利用先による採用を意味しない。外部利用先は対象、割り当て、現在の結び付き、および採用条件を独立して再検査する。これにより、ADR-0007で分離した結果の完全性と成果物採否を維持しながら、不正な構造を正式レビュー結果として受理することを防ぐ。

main外の試作ブランチにあるコミット`108987b`では、現行のUTF-8本文検証を通った不正な構造の結果を外部側で採用拒否できることを確認した。この決定は、その不足を受理境界でも閉じるものであり、外部側の再検査を置き換えない。
