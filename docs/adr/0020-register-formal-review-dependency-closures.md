# 正式レビュー統合で依存成果物を先に登録する

正式レビュー統合のレビュー対象登録は、依存要件と受け取った依存ファイルが同じ閉じた集合であることを検査し、依存成果物を先に、変更していないルート成果物を後に登録する。依存先の成果物識別子は統合モジュール内で確定し、ルート成果物だけがそれらを参照する。呼び出し元が任意の成果物識別子を依存先として渡す経路を設けないため、未登録依存の参照は要求の構造によって禁止する。

依存パスは正規化された相対パスに限定し、欠落、余分、重複、不正パス、バイト数不一致、およびダイジェスト不一致を登録前に拒否する。同じ登録要求識別子と同じ内容は同じ成果物へ合流させ、異なる内容では既存の成果物を置き換えない。

公開操作はADR-0019で決定したレビュー対象登録と設定済みPi拡張導入の2つを維持する。Runtime、Artifact Store、状態パス、および成果物資格情報は引き続き統合モジュール内へ隠し、成果物登録権限からオペレーションでの利用権限を推論しない。

本決定は、ADR-0019が初期境界に限って依存先を空に固定した制約を置き換える。Qoral固有の正規bundle検証、レビュー対象登録証跡、およびレビュー実行ワークスペースへの入力準備は扱わない。
