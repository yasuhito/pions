# 結果をオペレーション所有のUTF-8テキストとして保存する

ワーカーの最終回答1件は、汎用成果物ストアの登録、マニフェスト、結果受理予約、準備証跡、保持参照を介さず、オペレーションの永続記録と同じ私有ディレクトリにイベントストアが直接保存する。結果受理は1つのトランザクションとし、受理要求識別子の検査、既存上限とUTF-8妥当性の検査、正確なバイト列の永続化、そしてバイト数、SHA-256ダイジェスト、結果受理識別子を持つ`result_accepted`イベントの追記をこの順で行う。イベントの追記だけを公開確定点とし、バイト列の永続化と追記の間で中断した場合は未受理のままにする。結果受理識別子はオペレーション識別子、受理要求識別子、バイト数、ダイジェストから決定的に導出し、同じ内容の再送は同じ受理に合流させ、同じ受理要求で異なる内容は要求不一致、別の受理要求で異なる内容は結果衝突として拒否する。結果再取得はイベントストアから読んだバイト列を保存済みのバイト数とダイジェストで毎回検証し、不一致または欠落は破損、読み取り不能は検査不能として区別する。受理済みの結果は自動削除しない。

これにより結果の永続性と再取得がADR-0025の製品境界に閉じ、汎用保存機構の状態が結果の可用性に影響しなくなる。本決定はADR-0007のうち結果受理の前段に別の保存機構を置く部分を置き換え、Event Storeの`result_accepted`を唯一の公開確定点とする原則、およびADR-0013のRuntimeを結果再取得の正本とする原則は維持する。汎用成果物管理の削除はADR-0028で決定する。
