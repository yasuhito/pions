# ワーカープロファイル用途を明示して必要保証を検査する

ワーカープロファイルは、読み取り、正式レビュー、書き込み、改訂・再試行のいずれを候補用途とするかを`intendedUse`で必ず宣言する。ランタイムはオペレーションを作成する前に、正式レビューでは外部着手許可と固定レビュー対象検証、書き込みと改訂・再試行では外部着手許可、資源証明、権限目録、および必須の作業成果物要件を検査する。不足する保証を無効化した別設定へフォールバックしない。

用途を明示しなければ、同じ個別設定が安全性の異なる用途へ転用されても検出できない。用途と必要条件をワーカープロファイル検査境界で結び付けることで、各機能が実装済みであることと、用途に必要な保証が一体として構成済みであることを区別する。

`intendedUse`が候補用途を表すことは、本番プロファイルの登録または有効化を意味しない。既存の`pions_delegate`プロファイルは読み取り用途のままとし、正式レビュー、書き込み、改訂・再試行の有効化には段階導入判定記録と別途承認を必要とする。
