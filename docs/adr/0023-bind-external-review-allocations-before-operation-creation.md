# 外部レビュー割り当てをオペレーション作成前に予約する

Pionsは、信頼済み外部主体が発行した外部レビュー割り当てを正式レビューオペレーションの作成時に受理する。発行元を認証し、不透明なレビュー対象識別子、ワーカープロファイル、期限、および利用上限を照合した後、割り当てと束縛要求を作成予定のオペレーション識別子へ予約する。Pions自身は割り当てを発行せず、レビュー対象の内容を受理または検査しない。

予約はリポジトリ状態内のオペレーション横断台帳へ、排他制御と原子的なファイル置換を使って永続化する。同じ要求識別子と同じ内容は同じ予約へ合流させ、異なる内容、同じ割り当ての別オペレーションへの利用、期限切れ、および利用上限超過を拒否する。予約後にオペレーション作成が中断しても予約を未使用へ戻さず、同じ識別子から同じ作成予定オペレーションを復旧できるようにする。オペレーション作成時には予約と同じ外部レビュー割り当て束縛を変更不能な初期事実として保存する。

バンドル、引き渡し、対象版、レビュー軸、および外部実行識別情報は不透明な文字列として保存し、完全一致だけを検査する。予約や束縛の成立から、着手許可、実行再開、外部側の現在権限やワークフロー状態、または結果採用を推論しない。復旧照会は保存済み予約と束縛の取得に限り、旧オペレーションの許可、再開、または配送主体の引き継ぎには使用しない。
