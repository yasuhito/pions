# 表示終了処理を副作用より先に記録して復旧する

Pionsは成功したオペレーションの所有ペインを閉じる前に、表示終了処理識別子とHerdrの不透明なペイン識別子を結び付けた未完了記録をイベントストアへ永続化する。結果受理とワーカー停止確認が保存済みであり、Pionsが作成後に所有記録として永続化したペイン識別子がある場合だけ未完了記録を作る。Herdrのペイン識別子は閉鎖後に再利用されない安定した識別子であるため、現在のペイン一覧に同じ識別子が存在することを同一性確認とする。ワーカー識別記録のペイン項目は所有記録から設定されるため、独立した同一性証拠には使用しない。

終了処理は未完了記録の保存後に現在のペイン一覧を再照合し、一致した場合だけcloseする。close後に完了記録を保存し、照合不能、対象消失、またはclose失敗は未確認として記録する。ランタイム復旧時には未完了記録を列挙して同じ照合を繰り返し、記録の存在だけからcloseを再実行しない。表示終了処理の完了はワーカー以外の関連実行主体や外部資源の停止を証明せず、再試行安全証明として公開しない。

イベントストアへ診断を保存できない場合でも受理済みの結果を失敗へ変えない。`OperationHandle.result()`は意味上の`Result`、表示終了処理証跡、および終了処理診断を分離した完了応答を返す。保存失敗の診断はこの直接応答だけに含め、版付き`OperationSnapshot`へ揮発情報を混入しない。永続化済みの終了処理証跡と診断は`OperationSnapshot`から再取得できる。

この決定は、可視ワーカーと成功ペインの終了責任を定めたADR-0005、および結果受理を表示や採用から分離したADR-0007を具体化する。
