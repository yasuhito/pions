# レビュー対象をオペレーションごとに解決する

正式レビューのレビュー対象はワーカープロファイルへメタデータを設定せず、オペレーション作成時に指定された登録済み成果物識別子からArtifact Storeが解決したメタデータを固定する。プロファイルはモデル、思考量、ツール、着手許可、検証、保持などの保証だけを所有し、呼び出し元がレビュー対象のバイト数、ダイジェスト、形式、正規化規約を自己申告する経路を設けない。メタデータ解決ではバイト列を検証せず、レビュー対象と依存閉包に対する現在の利用権限を独立した信頼済み主体へ再検査し、保持した後の完全性検証を許可要求公開の条件とする。
