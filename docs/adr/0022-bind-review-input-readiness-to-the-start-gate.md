# レビュー入力準備完了を着手ゲートへ束縛する

Pionsは、正式レビューの検証済み依存閉包をオペレーション専用の入力先へ書き込んだ後、許可されたファイル集合、各バイト列、集合ダイジェスト、入力書き込み終了、および入力先への固定を照合する。照合結果は、対象オペレーション、レビュー対象登録証跡、資源アダプターの登録、資源取得処理、入力先、書き込み権限、およびファイル集合を束縛する変更不能なレビュー入力準備完了として起動証跡へ保存する。準備完了が成立するまでは着手許可要求を公開しない。

開始指示の配送直前には、同じ資源取得処理について現在の競合保護と利用権限を再検査し、閉じた入力先から全ファイルを読み戻して準備完了と再照合する。資源保護の失効、中断、検査不能、オペレーションや入力先の不一致、期限切れ、キャンセル、ファイルの欠落・追加・差し替えのいずれかを検出した場合は開始指示を配送しない。入力準備の拒否は既存の資源証明拒否として取得でき、新しい最上位オペレーション状態は追加しない。

レビュー入力準備完了は準備時点の事実であり、その後の不変性、元リポジトリの不可視性、実行中のアクセス強制、または本番ホストの隔離を証明しない。これらの継続的な保証は外部の資源アダプターと資源証明が担う。本決定はADR-0017の準備完了を永続化し、ADR-0006の着手ゲートへ接続する。
