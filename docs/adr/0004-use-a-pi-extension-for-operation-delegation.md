# Pi拡張からオペレーションを委譲する

Pionsは、Piからワーカーへ作業を委譲する入口として、プロジェクトローカルのPi拡張が登録する`pions_delegate`ツールを使用する。1回のツール呼び出しは1つの`Operation`に対応し、ツールの入力は自己完結した作業内容だけに限定する。モデル、思考レベル、ツール、作業ディレクトリ、永続化、表示、キャンセルの方針は拡張と`Runtime`が決定し、呼び出すモデルには公開しない。

これにより、既存のスキルは「サブエージェントへ委譲する」という指示を変更せずにPionsを利用でき、CLIの起動、ワーカープロトコル、非公開ファイル、Herdrペインの詳細を知る必要がない。複数の独立した委譲は、複数タスクを受け取るPions固有のインターフェースではなく、Piの並列ツール実行によって構成する。

初期の拡張は読み取り中心のワーカーに限定し、具体的な役割は委譲された作業内容で指定する。`bash`の読み取り専用利用は指示上の方針であり、隔離とはみなさない。指定モデルが利用不能な場合は委譲元モデルへ暗黙にフォールバックせず、失敗を明示する。Herdrを利用できない場合も画面を持たない実行へ切り替えない。
