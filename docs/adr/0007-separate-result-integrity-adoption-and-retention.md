# 結果の完全性、採用、保持を分離する

正式なレビュー対象と作業成果物は、再生成されるGit差分や存続中のワークスペースではなく、固定した最終バイト列と取得可能な依存を正本にする。テキストと要求された作業成果物の完全性・永続化を結果受理の条件とするが、来歴の正しさ、適用成功、テスト合格、成果物採否とは区別する。

改訂と再試行は元のOperationを変更せず、終端状態の不変性も維持する新しいOperationとして表し、再試行結果の系列への採用は別権限による不変の判断にする。履歴参照とバイト列を保護する保持参照を分離することで、監査関係を残したまま方針による削除を可能にする。

これによりGit環境差による同一性の揺れ、自動再試行による上限回避、永久参照による削除不能を避ける。初期のGit差分再生成形式は採用しない。詳細は[設計契約](../external-start-and-revision.md)を参照する。本決定は実装完了を意味しない。
