# レビュー対象登録証跡を成果物ストアへ保存する

正式レビュー統合は、信頼済み発行元が申告したレビュー対象メタデータを、設定済みの版付き検証主体が実際のルートと依存ファイルから検証した結果と照合する。発行元の認証と内容検証は別のインターフェースで行い、どちらかが不明または不一致ならレビュー対象登録証跡を作らない。

検証済みの依存成果物、ルート成果物、レビュー対象登録証跡の順に確定する。証跡は成果物ストア内の独立した変更不能な記録としてルート成果物識別子から解決し、成果物としては登録せず、ルート成果物の依存先にも加えない。証跡はルート成果物、正規化済み依存パスと成果物識別子の一対一対応、各バイト数とダイジェスト、外部形式の集合ダイジェスト、発行元、および版付き検証主体を束縛し、証跡自身の識別子とダイジェストを持つ。

Runtimeは正式レビューオペレーションの作成時に、指定されたルート成果物から登録証跡を解決し、その識別子とダイジェストを起動証跡へ固定する。呼び出し元やモデルに証跡を選ばせず、登録証跡の成立から成果物利用権限、着手許可、結果受理、または成果物採否を推論しない。

本決定は、ADR-0020が扱わなかったレビュー対象登録証跡を追加する。Qoral固有のバンドル形式、正規集合ダイジェスト算法、およびレビュー入力準備は扱わない。
