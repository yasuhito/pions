# 着手許可と資源管理の権限を分離する

Pionsは起動証跡に結び付く外部着手許可を永続化し、開始直前の再照合後にだけワーカーへ開始指示を配送する。外部コーディネーターは成果物採否と外部資源の後始末判断、ランチャーと資源アダプターはワークスペースや利用権の証明を所有し、Pionsはそれらを検査するが資源管理や技術的な隔離を内包しない。

handleの読み取り権限、着手許可権限、成果物採否権限、資源利用権限を分離することで、単一の承認フラグから権限が拡大することを防ぐ。宣言、観測、強制を独立した保証とし、不足する保証は暗黙に補わず起動を拒否する。

ADR-0004の読み取り中心の既定入口は維持し、信頼済み構成による読み取りゲートと許可必須の書き込み経路を追加する設計とする。ADR-0005の自動開始境界を、必要なプロファイルでは外部許可・再照合・安全な再配送へ拡張する。本決定は設計の承認であり、実装またはプロファイル有効化の承認ではない。詳細は[設計契約](../external-start-and-revision.md)を参照する。
