# 汎用成果物管理を契約から取り除く

Pionsの保存対象は、オペレーションが直接所有する変更不能なUTF-8結果本文だけとする。ワーカーから受け取る結果契約は、本文、正確なバイト数、SHA-256ダイジェスト、および受理要求識別子に限定する。結果はオペレーションの私有記録ディレクトリへ保存し、結果受理イベントを公開確定点として、完全取得、UTF-8境界を守る断片取得、冪等な再受理、および再起動後の再取得を提供する。

ファイル、添付、バイナリ、作業成果物、依存関係をPionsへ取り込む経路は設けない。成果物形式登録、成果物の採否、保持期限、保持参照、自動削除、ガベージコレクション、およびそれらの資格情報や障害分類も契約と永続状態から取り除く。共有作業ディレクトリでワーカーが変更したファイルはその場所に残し、Pionsの保存領域へ複製しない。受理済み結果は利用者がPionsの保存領域を明示的に削除するまで保持し、Pions自身は保持ライフサイクルを管理しない。

ADR-0027の結果保存方式を唯一の保存経路とし、オペレーション所有の結果以外を保存する旧経路は維持しない。
