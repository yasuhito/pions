# 正式レビュー統合を専用の公開境界から提供する

信頼済みホスト向けの正式レビュー統合は、`pions/formal-review`を安定した公開入口とする。この入口は、固定ルート成果物の登録と設定済みPi拡張の導入だけを操作として公開する。Runtime、Artifact Store、リポジトリごとの状態パス、資格情報、復旧処理、およびテスト専用差し替えは、同じ統合モジュールの内側に置く。

成果物登録とPiセッションが同じリポジトリ状態を使う規則をモジュール内で一元化することで、利用先が私有ディレクトリ構成や広い成果物権限を組み立てる必要をなくす。依存成果物を含む登録はこの初期境界へ追加せず、ルート成果物の依存先を空に固定する。正式レビュー設定がない場合もPiツールは登録し、実行時に安全側で拒否する。読み取り用プロファイルへの切り替えは行わない。

この公開境界による候補プロファイルの構成は、本番正式レビュープロファイルの登録、有効化、または段階導入の承認を意味しない。
