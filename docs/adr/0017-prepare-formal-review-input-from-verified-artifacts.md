# 検証済み成果物から正式レビュー入力を準備する

Pionsは、レビュー対象登録証跡に固定された成果物の依存閉包を広い成果物権限の内側で取得・検証し、外部の資源アダプターが所有するオペレーション専用のレビュー実行ワークスペースへ、狭いインターフェースを通して書き込む。汎用の成果物ストアや広い成果物資格情報を利用先へ公開せず、ファイル集合と全バイト列の再検証、入力書き込みの終了、およびワーカー入力先への固定によってレビュー入力準備完了を確定してから着手ゲートを通過させる。

ワークスペースの作成・所有、実行中のアクセス強制、停止・遮断、削除は外部の資源アダプターが担い、Pionsは所有権や削除権限を取得しない。これにより、ADR-0014で固定したレビュー対象とワーカーが実際に読む入力を同じバイト列へ結び付けつつ、ADR-0006で分離した資源管理と技術的隔離の責任をPionsへ取り込まない。準備完了はその時点の事実であり、その後の不変性や本番環境の隔離を証明しない。

この決定の実現可能性は、throwaway branchのcommit `108987b`に保存した固定入力prototypeで確認した。prototypeは本番の資源アダプター、アクセス隔離、並行実行、またはQoralによる採用を証明しない。
