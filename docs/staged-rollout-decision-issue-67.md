# Issue #67 段階導入判定記録

> [!NOTE]
> この判定はADR-0025で失効した。正式レビューは製品境界と公開契約から削除され、
> `pions/formal-review`も配布パッケージから利用できない。現行の製品境界は
> [ADR-0025](adr/0025-focus-pions-on-durable-delegation.md)を参照する。

## 判定

信頼済みブートストラップと非本番アダプターによる正式レビュー統合は、非本番の検証用途に限って利用可能とする。本番の正式レビューは無効のままとし、本Issueの完了をプロファイル登録、有効化、または運用承認として扱わない。

既存の読み取り用途は変更しない。`pions_delegate`と通常の`.pions.json`によるモデルおよび思考量の選択だけを引き続き有効とする。

## 検証した保証

- グローバル導入した配布物の`pions/formal-review`を、別の利用先リポジトリに配布物を複製せず読み込める。
- 公開モジュールの契約版、利用先の正規ルート、資源アダプターの識別子・版・登録成果物ダイジェスト・用途を信頼済みブートストラップから照合する。
- 正規ルート、モジュール版、アダプターダイジェスト、承認一覧の不一致を安全側で拒否する。登録成果物と実際の実行関数の対応は信頼済み登録主体の責任であり、Pionsによるダイジェスト検査だけでは証明しない。
- 本番構成では非本番アダプター、内部テスト差し替え、および正式レビュー設定を拒否する。
- 非本番構成では、公開統合モジュールからレビュー対象登録、独立した二軸オペレーション、起動証跡、着手判断、結果受理、結果再取得、および外部ブリッジが使う状態参照を取得できる。
- 通常の`.pions.json`はアダプター読込先、資格情報、プロファイル権限、正式レビュー有効化範囲を受け付けない。

## 残る未達条件

本番有効化には、少なくとも次の証拠と別の段階導入承認が必要である。

- 本番資源アダプターと正規ランチャーによる、元リポジトリへのアクセス拒否を含む実行中の資源強制
- 秘密情報と短命の有効化材料をモデル、タスク、設定、ツール入出力、ログ、結果へ露出しない配送経路
- ワーカー、子プロセス、外部ジョブの停止または実効的なアクセス遮断、および資源解放を対象環境で確認する障害試験
- 本番正式レビュープロファイル、主体登録、権限目録、保持方針、後始末方針の承認
- 運用責任者による段階導入判定

単体テストと非本番統合テストの合格は、レビュー入力準備時点の束縛を検証するが、本番ホストの継続的なアクセス隔離を証明しない。上記が満たされるまで、本番正式レビューを有効化しない。
