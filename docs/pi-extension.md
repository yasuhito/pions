# Pi拡張から作業を委譲する

信頼済みのPionsプロジェクトでは、プロジェクトローカルのPi拡張が`pions_delegate`ツールを登録する。利用前に`npm run build`を実行し、可視ワーカー用の内部拡張を生成しておく。

`pions_delegate`は、独立したコンテキストへ渡す自己完結した`task`だけを受け取る。モデル、思考レベル、ツール、作業ディレクトリ、状態保存先はツール入力では変更できない。1回の呼び出しは1つのルート`Operation`に対応し、複数の独立した作業はPiの並列ツール実行によって構成する。

初期のワーカーはHerdrの兄弟ペインで、Pi公式の`regular` TUIを持つ一時セッションとして動く。利用可能な領域が横長なら右、縦長なら下へ、フォーカスを移さずペインを作成する。委譲元セッションのモデルと思考レベルを継承し、`read`、`grep`、`find`、`ls`、`bash`だけを利用する。ワーカーには`bash`を読み取り目的だけに使うよう指示するが、これは技術的な読み取り専用隔離でもセキュリティサンドボックスでもない。ワーカーは信頼済みプロジェクトの`AGENTS.md`とPions内部拡張だけを読み込み、通常のスキル、拡張、プロンプトテンプレート、追加テーマは探索しない。TUIは観測専用であり、端末からの入力はすべて破棄する。

## レビュー用モデルの設定

リポジトリルートの`.pions.json`で、レビュー用のモデルと思考レベルを上書きできる。

```json
{
  "review": {
    "model": {
      "provider": "anthropic",
      "id": "claude-opus-5"
    },
    "thinkingLevel": "high"
  }
}
```

`model`または`thinkingLevel`を省略すると、その値だけを委譲元セッションから継承する。`thinkingLevel`には`off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`のいずれかを指定する。モデルはプロバイダーとモデル識別子の正確な組で指定する。

設定には認証情報を記載しない。PionsはPiのモデルレジストリーと既存の認証を使用する。不正なJSON、未知のキー、不正な値は委譲を開始せずに拒否する。指定モデルがモデルレジストリーにない場合、認証されていない場合、またはワーカーで別のモデルが選択された場合も、委譲元モデルへ切り替えず型付き失敗を返す。

作業内容とオペレーション権限は所有者だけが読み書きできるファイルで渡す。プロセス引数、オペレーションイベント、ログ、Herdrメタデータには本文を含めない。内部拡張が認証済みの`begin`を受信した後にだけ、作業内容をTUIの通常のユーザーメッセージとして投入する。状態は`XDG_STATE_HOME`が絶対パスならその配下、未指定または相対パスなら`~/.local/state`配下へ保存する。さらに、正規化したリポジトリルートのダイジェストでリポジトリごとに分離する。

Herdr環境がない場合でもツールの登録は維持される。実行すると`HerdrPreconditionError`になり、画面を持たない実行へは切り替えない。ワーカー失敗も自動再試行せず、`Operation`識別子と型付きの理由を含む失敗として呼び出し元へ返す。成功時は永続化済み`Result`の本文を返し、診断情報として`Operation`識別子、バイト数、ダイジェストを付ける。結果受理の確認後にPiへ正常終了を要求し、開始トークンを含むプロセス識別情報で停止を確認する。停止を証明できた成功オペレーションでは、永続記録されたPions所有のペインだけを自動で閉じる。ペイン閉鎖に失敗しても受理済みの結果と終端完了は維持し、表示後処理の失敗をオペレーションへ記録する。結果受理、Pi終了、または停止を証明できない場合と、失敗またはキャンセルの場合は、ペインを調査用に保持する。

親のモデルコンテキストへ返す本文は、切り詰め通知を含めてPi標準の2000行または50KB以内に収める。切り詰めた場合も完全な`Result`は永続記録に残り、通知と診断情報の`Operation`識別子から参照できる。

## セッションとオペレーションの寿命

ツール実行がPiから中断された場合、`pions_delegate`は対応する稼働中`Operation`へ部分木キャンセルを1回要求し、Pionsが停止の証拠を分類するまで待つ。結果待ちをローカルで中断したことや、プロセスへシグナルを送れたことだけではキャンセル成功としない。停止を証明できない場合は`OperationUnknownError`、証明できた場合は`OperationCancelledError`としてオペレーション識別子とともに呼び出し元へ返す。

Piセッションの終了、新規作成や再開による切り替え、フォーク、拡張の再読み込みでは、拡張の終了処理が追跡中のすべての稼働中`Operation`へ部分木キャンセルを要求し、すべての分類が終わるまで待つ。中断経路同士が重なっても、同じ`Operation`への要求は1回にまとめる。キャンセル済み、停止を証明できない状態、キャンセル処理の失敗のいずれでも、Pions所有のHerdrペインと永続的な`Operation`記録は削除せず、調査に利用できる状態で保持する。

## モデルによる委譲の選択

ツールの説明と利用指針は、サブエージェントへの委譲や独立したコンテキストでの調査に`pions_delegate`を使い、独立した複数の作業をPiの並列ツール実行で構成するようモデルへ伝える。特定のスキル名や本文を検出する処理は持たない。この説明によってモデルがツールを選ぶことは形式的な保証ではなく、実モデルによる確率的な振る舞いである。Issue #23で実施した受け入れ確認は[手動スモークテスト](manual-smoke-test-issue-23.md)に記録する。
